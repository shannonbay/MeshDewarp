STEP 1: DBNet Inference & Heatmap Generation
- Input: Preprocess camera frame to model input size (e.g., 640x640).
- Normalization: Apply ImageNet mean/std (crucial for DBNet accuracy).
- Inference: Execute TFLite model to get a single-channel Probability Map.
- Binarization: Threshold the map (prob > 0.3) to create a binary text mask.

STEP 2: Baseline Extraction (Skeletonization)
- Contour Finding: Use Imgproc.findContours on the binary mask to get text "ribbons."
- Filtering: Discard small contours (noise) based on area.
- Point Sampling: For each ribbon, extract points along the top and bottom edges.
- Medial Axis: Average the top/bottom points to find the "center-line" points of the text.

STEP 3: Piecewise Cubic B-Spline Fitting
- Knot Placement: Define "knots" at regular horizontal intervals (e.g., every 10% of width).
- Spline Construction:
    - Use a B-Spline library (or a Least Squares solver) to fit a cubic spline to the center-line points.
    - Result: A continuous function S(x) that represents the "flow" of that specific text line.
- Sharp Fold Handling: Increase knot density in areas where the derivative (slope) changes rapidly.

STEP 4: Global Mesh Generation
- Grid Sampling: Create an M x N grid of control points (e.g., 15 columns by 20 rows).
- Vertical Alignment:
    - For each column, calculate the "average vertical offset" from all splines passing through that x-coordinate.
    - Adjust the y-coordinate of every grid point in that column by this offset.
- Result: A distorted grid that perfectly mirrors the physical distortion of the paper.

STEP 5: Image Rectification (Remapping)
- Target Grid: Create a perfectly uniform rectangular grid of the same dimensions.
- Map Creation: Use OpenCV to convert the Distorted Grid vs. Uniform Grid into 'map_x' and 'map_y' float matrices.
- Execution: Call Imgproc.remap(src, dst, map_x, map_y, INTER_CUBIC).
- Output: A flattened, rectified image where text lines are horizontal and parallel.
